# メモアプリ（ローカルファイル管理版）

このプロジェクトは、ReactフロントエンドとNode.js/Expressサーバーで構成されたアプリです。ハイライト・メモ情報は`memos.json`ファイルで一括管理されます。メモ内容は自由に変更してください。

---

## 必要な環境
- Node.js（v16以上推奨）
- npm

---

## セットアップ手順

### 1. 依存パッケージのインストール

```sh
npm install
```

### 2. サーバー用依存パッケージのインストール

```sh
npm install express cors
```

---

## 起動方法

### 1. APIサーバーの起動

```sh
node server.js
```
- サーバーはデフォルトで http://localhost:4000 で起動します。
- メモデータは `memos.json` に保存されます。

### 2. Reactアプリの起動

別のターミナルで以下を実行：

```sh
npm start
```
- 通常 http://localhost:3000 でアプリが開きます。

---

## 機能
- メモの追加・削除・リンク
- メモ情報はAPI経由で`memos.json`に保存
- iPhone Duo（折りたたみ型iPhone）対応
  - 閉じた状態（外側ディスプレイ）：メモを縦に2つ並べて表示
  - 開いた状態（内側ディスプレイ）：見開きの左右の画面にメモを1つずつ表示し、折り目に文字がかからないよう間隔を空ける
  - 左右スワイプでページ送り
  - ノッチ・ホームインジケーターを避けた余白

---

## スマートフォン実機での確認

PCと同じWi-Fiにつないだ iPhone などから `http://<PCのIPアドレス>:3000` を開くと確認できます。
APIはページを開いたホスト名の4000番ポートに自動で接続します。別の場所のAPIを使う場合は、環境変数 `REACT_APP_API_URL` で指定してください。

---

## 注意事項
- サーバー（`server.js`）は必ず起動しておいてください。
- フロントエンドとAPIサーバーは別ポートで動作します。
- `memos.json`が壊れた場合は手動で修正してください。
